# 密码保险箱（Password Vault）

一个本地运行的 Windows 密码管理器：把各个网站的账号密码都存在一个加密保险箱里，找密码、复制密码几秒钟搞定，不用再到处找密码。

## 功能

- **存密码**：网站、网址、账号、密码、分类、收藏、备注；随时添加、修改、删除
- **找密码**：顶部搜索（网站 / 账号 / 备注都能搜），左边按分类筛选（社交 / 购物 / 学习 / 游戏 / 工作 / 银行 / 其他），只看收藏
- **用密码**：一键复制账号、密码、网址；复制后 30 秒自动清空剪贴板；密码平时显示为 `••••••••`，点一下才显示；填了网址可以一键打开网站
- **强密码生成器**：长度 8–32 位，大小写字母 + 数字 + 符号自由搭配，带强度与熵值提示
- **安全提醒**：弱密码、重复密码会自动标出来，侧边栏有统计
- **自动锁定**：默认 5 分钟不用自动锁屏，也可以在设置里改时间或手动锁定
- **备份与导出**：导出加密备份（只能用主密码打开）、导入备份、导出明文 CSV 表格（换电脑时用，导完请立即删掉文件）
- **修改主密码、清空全部数据**都在设置里

## 安全

- 所有密码都用你的主密码加密（PBKDF2 25 万次迭代 + AES-256-GCM）后存在这台电脑本地，**不联网、不上传**。
- 主密码本身不保存在任何地方，只在你输入的那一刻用来解密，锁屏后就从内存里清除。
- 界面：渐变锁屏、深色侧边栏、玻璃拟态卡片、每个网站一个渐变字母头像。

⚠️ **主密码忘了就打不开了，里面的密码也找不回来，请务必记住。建议定期在设置里导出一次加密备份。**

## 使用方法

### 直接运行（Windows 64 位）

1. 下载最新 Releases 里的压缩包，解压到任意文件夹（不要只解压 exe 一个文件）。
2. 双击 `password-vault.exe` 即可打开，不需要安装，不需要联网。
3. 第一次打开先设置一个主密码（至少 8 位）。

### 从源码运行 / 打包

```bash
npm install
npm start          # 开发运行
npx @electron/packager . password-vault --platform=win32 --arch=x64 --overwrite --out dist
```

需要 Node.js 18+。打包产物在 `dist/password-vault-win32-x64/`。

## 技术栈

- Electron 31 + 原生 HTML / CSS / JavaScript
- WebCrypto（PBKDF2 + AES-GCM），无任何第三方依赖的加密代码
- 数据存储：localStorage（Electron 用户数据目录）
